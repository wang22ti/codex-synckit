# Codex SyncKit 0.3.1-alpha

Shared global memory now carries a portable .memory-no-git marker. The bundled
memory tools skip Git initialization and commits for that tree, including calls
from automatic capture and scheduled maintenance. Memory content continues to
be recorded and synchronized.

New exports create the marker. Installation or repair adds it for linked global
memory, including links that are already current. Existing .git directories
remain intact until their owner explicitly archives or removes them.

This release also includes the previously merged conversation-title synchronization,
five-result automation-history retention, and nominal schedule watermark fixes.

Download the ZIP and its SHA-256 checksum from this release. For an existing Kit,
update the bundled memory skill and installer, then run the generated installer
with -Repair. Synchronize the marker and updated skill to every participating PC
before relying on the guard there.

The shell regression covers capture and maintenance with automatic Git enabled,
all three Git commands, namespace overrides, parent-repository protection, and
ordinary Git behavior in unmarked memory directories.
