# Codex SyncKit 0.3.0-alpha

This release adds custom sidebar section synchronization and prevents dependency
trees from overwhelming OneDrive. It also repairs paginated task restoration in
place, preserving task IDs, names, and original history.

- **Sidebar sections:** synchronize names, order, collapsed state, and project/
  task membership. Managed Pull reconciles the receiving machine's native
  section tables with local backups; SQLite databases remain device-local.
- **Task restoration:** correct history-mode mismatches, empty native names,
  and stale cross-device rollout paths. Normal repair no longer requires a
  recovery-suffixed task copy. The earlier recovery utility remains available
  for compatibility and is not invoked by Managed repair.
- **OneDrive exclusions:** recommended setup and repair install 15 exact folder
  names covering Node dependencies, Python caches/environments, build caches,
  and reserved scratch space. Existing custom registry entries are preserved.
- **Workspace filtering:** prune matching directories and actual links before
  copying/hashing. Old excluded baseline entries cannot trigger file deletion.

## Update on another Windows PC

Allow OneDrive to download the updated private Kit, fully close ChatGPT, then
start `Start-CodexManaged.vbs`. The first installation of missing machine policy
may request Windows UAC and restart OneDrive. You can explicitly skip this step
with `-SkipOneDriveExclusions` when running the generated installer.

The folder policy affects matching folder names across that Windows machine.
It does not remove previously uploaded content or guarantee that old queues
clear immediately. General `tmp`, `.git`, source, conversation history, and
deliverables are not globally excluded. Update OneDrive if its installed policy
template does not support folder exclusions.

Regression coverage includes PowerShell 5.1 export/install/Managed lifecycle,
sidebar imports/renames/deletions, task catalog repair, additive registry policy,
and dependency/link filtering. Source and extracted release archives pass the
public-data and credential gates. This remains an early alpha; keep backups.
